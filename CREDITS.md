# CREDITS

## Motor y GUI

- Motor: [Ren'Py](https://www.renpy.org/) 8.5.3 — gratuito para uso comercial y no comercial.
- La interfaz (`gui.rpy`, `screens.rpy`, `game/gui/*`) se deriva del proyecto de ejemplo *The Question* incluido en el SDK de Ren'Py, recoloreada para JogoPro. Créditos del GUI base: equipo de Ren'Py (PyTom) y autores de *The Question*.

## Escritura

- Historia y diseño narrativo: `Historia.md`, `ArbolDecisiones.md`.
